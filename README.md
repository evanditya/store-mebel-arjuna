# mebel_arjuna Store

Full-featured e-commerce marketplace generated by **STM Converter**. Built with Next.js 14 + Python FastAPI + PostgreSQL. Includes seller dashboard, buyer registration, shopping cart, Midtrans payment gateway, and Biteship shipping integration.

---

## Quick Start (Replit) - Recommended

### Step 1: Import Repository
1. Go to [replit.com](https://replit.com) and click **Create Repl**
2. Select **Import from GitHub**
3. Paste this repository URL
4. Click **Import from GitHub**

### Step 2: Add PostgreSQL Database
1. In your Repl, open the **Tools** panel (left sidebar)
2. Search for **PostgreSQL** and click **Add**
3. The `DATABASE_URL` environment variable will be set automatically

### Step 3: Add API Keys (Secrets)
Open the **Secrets** tab in your Repl and add the following:

| Secret Name | Description | Where to Get |
|---|---|---|
| `MIDTRANS_SERVER_KEY` | Midtrans server key for payment processing | [Midtrans Dashboard](https://dashboard.sandbox.midtrans.com) > Settings > Access Keys |
| `MIDTRANS_CLIENT_KEY` | Midtrans client key for Snap popup | Same as above |
| `MIDTRANS_IS_PRODUCTION` | Set to `true` for live payments (default: `false`) | Set manually |
| `BITESHIP_API_KEY` | Biteship API key for shipping rates & tracking | [Biteship Dashboard](https://biteship.com) > Settings > API Keys |
| `SESSION_SECRET` | Random string for JWT sessions | Auto-generated if not set |

### Step 4: Run
Click the **Run** button. The app will:
- Install all dependencies automatically
- Set up the database tables
- Seed product data from `backend/seed_data.json`
- Start the frontend (port 5000) and backend (port 8000)

## Payment Gateway - Midtrans

### Setup

1. **Create Account**: Register at [Midtrans](https://midtrans.com)
2. **Get API Keys**:
   - **Sandbox** (testing): [dashboard.sandbox.midtrans.com](https://dashboard.sandbox.midtrans.com) > Settings > Access Keys
   - **Production** (live): [dashboard.midtrans.com](https://dashboard.midtrans.com) > Settings > Access Keys
3. **Add to Secrets/Environment**:
   - `MIDTRANS_SERVER_KEY` = Your Server Key
   - `MIDTRANS_CLIENT_KEY` = Your Client Key
   - `MIDTRANS_IS_PRODUCTION` = `false` (sandbox) or `true` (production)

## API Documentation

Once the backend is running, visit `/docs` on port 8000 for interactive Swagger API documentation.

Key endpoints:
- `POST /auth/login` - Login (buyer/seller)
- `POST /auth/register` - Register buyer account
- `GET /products` - List all products
- `GET /products/{slug}` - Product detail
- `POST /cart/add` - Add to cart
- `POST /payment/create` - Create Midtrans payment
- `POST /shipping/rates` - Calculate shipping rates
- `GET /orders` - List orders

## Troubleshooting

### Database not connecting
- On Replit: Make sure PostgreSQL is added from the Tools menu
- Locally: Check `DATABASE_URL` in `.env` matches your PostgreSQL setup

### Payment not working
- Verify `MIDTRANS_SERVER_KEY` and `MIDTRANS_CLIENT_KEY` are set correctly
- Use sandbox keys for testing, production keys for live
- Check Midtrans Dashboard for transaction logs

### Shipping rates not loading
- Verify `BITESHIP_API_KEY` is set
- Check if the API key is active in Biteship Dashboard
- Use test/sandbox key for development
